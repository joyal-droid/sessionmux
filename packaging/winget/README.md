# winget manifests

Manifests for the winget package `Sessionmux.Sessionmux`, in the folder layout of
[microsoft/winget-pkgs](https://github.com/microsoft/winget-pkgs):
`manifests/s/Sessionmux/Sessionmux/<version>/`.

Placeholder to fill for each release: `<sha256>` (the installer hash from the release's
`SHA256SUMS`; winget accepts either case). The update and submission steps are in
[MAINTAINING.md](../../MAINTAINING.md#winget).
